# CareerConnect

CareerConnect is a simple responsive job portal frontend created for a ReactJS Sessions 1–12 assignment.

## Technologies

- ReactJS
- JSX
- Vite
- React Router
- Bootstrap
- CSS
- JavaScript

## Components

- Navbar
- HeroSection
- SearchBar
- JobCard
- CompanyCard
- CategoryCard
- Footer

## Pages

- `/` Home
- `/jobs` Jobs
- `/jobs/:id` Job Details
- `/companies` Companies
- `/applications` Applications
- `/profile` Profile
- `*` 404 Page

## Features

- 6 sample jobs
- 4 companies
- 6 job categories
- Props
- useState
- onClick
- onChange
- onSubmit
- Job search
- Save Job toggle
- Apply Now interaction
- Dynamic job details
- Profile editing
- Responsive Bootstrap layout
- Active navigation links

## Run the project

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
